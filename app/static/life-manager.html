Authorized document search

AETHER searches only the absolute folders you explicitly list in DOCUMENT_ALLOWED_ROOTS. Text extraction supports TXT, Markdown, logs, PDF and DOCX. Scanned PDFs need OCR, which is not enabled.

Choose authorized folders in your server configuration first.
